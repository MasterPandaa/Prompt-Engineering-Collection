# Snake Game (Pygame)

Game Snake klasik dibuat dengan Python dan Pygame.

## Spesifikasi
- Layar: 600 x 400 piksel.
- Kontrol: panah (Atas, Bawah, Kiri, Kanan). Tidak bisa berbalik arah secara langsung.
- Makanan muncul acak dan sejajar grid.
- Saat makan, ular bertambah panjang 1 segmen dan skor +1.
- Game Over jika menabrak dinding atau tubuh sendiri.
- Skor tampil di layar.

## Persyaratan
- Python 3.8+

## Instalasi
```bash
pip install -r requirements.txt
```

## Menjalankan
```bash
python snake_game.py
```

## Kontrol Tambahan
- R: restart ketika di layar Game Over
- ESC: keluar
