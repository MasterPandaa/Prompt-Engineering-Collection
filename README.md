# Snake Game (Pygame)

Layar 600x400, block 20x20, kontrol tombol panah, ular tidak bisa berbalik arah, makanan acak, skor, dan deteksi tabrakan dinding/tubuh.

## Cara Menjalankan (Windows)

1. Pastikan Python sudah terinstal (disarankan Python 3.9+).
2. (Opsional) Buat virtual env.
3. Install dependensi:

```bash
pip install -r requirements.txt
```

4. Jalankan game:

```bash
python snake.py
```

Kontrol:
- Panah untuk bergerak.
- Menabrak dinding atau tubuh sendiri = Game Over.
- Di layar Game Over: tekan `R` untuk restart, `Q` atau `Esc` untuk keluar.
