# Snake Game (Pygame)

Game Snake klasik menggunakan Python dan Pygame.

## Spesifikasi
- Layar: 600x400 piksel
- Kontrol: Arrow keys (atas, bawah, kiri, kanan)
- Tidak bisa langsung membalik arah 180 derajat
- Makanan muncul acak, skor +1 setiap dimakan, panjang ular bertambah 1
- Game over saat menabrak dinding atau tubuh sendiri

## Cara Menjalankan (Windows)
1. Pastikan Python sudah terpasang (3.8+ direkomendasikan).
2. Buka terminal/PowerShell pada folder proyek ini.
3. Install dependency:
   ```powershell
   python -m pip install -r requirements.txt
   ```
4. Jalankan game:
   ```powershell
   python snake.py
   ```

## Kontrol Tambahan
- Saat Game Over: tekan `R`/`Enter`/`Space` untuk restart, `Q` atau `Esc` untuk keluar.

Selamat bermain!
