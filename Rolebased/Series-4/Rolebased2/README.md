# Tetris (Python + Pygame)

OOP Tetris dengan ghost piece.

## Requirements

- Python 3.8+
- Pygame (lihat `requirements.txt`)

## Instalasi

Di PowerShell (Windows):

```
py -m pip install -U pip
py -m pip install -r requirements.txt
```

## Menjalankan

```
py tetris.py
```

## Kontrol

- Left/Right: Gerak kiri/kanan
- Down: Soft drop
- Up atau X: Rotasi searah jarum jam
- Z: Rotasi berlawanan jarum jam
- Space: Hard drop
- P: Pause
- Esc: Keluar
