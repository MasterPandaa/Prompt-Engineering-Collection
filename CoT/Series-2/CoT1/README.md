# Snake Game (Pygame)

Game Snake klasik menggunakan Pygame.

## Persyaratan
- Python 3.8+
- Pygame

## Instalasi
```
pip install -r requirements.txt
```

## Menjalankan
```
python snake_pygame.py
```

## Kontrol
- Panah Atas/Bawah/Kiri/Kanan: Mengubah arah ular
- R atau Space: Restart ketika Game Over
- ESC atau Q: Keluar

## Catatan
- Grid: Ukuran layar `(640x480)` dan `BLOCK_SIZE=20` sehingga semua gerakan selaras grid.
- Kecepatan game diatur melalui `FPS` di bagian atas file `snake_pygame.py`.
