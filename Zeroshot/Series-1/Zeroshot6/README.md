# Pong (Python, Pygame)

Permainan Pong sederhana menggunakan Python dan Pygame.

## Spesifikasi
- Resolusi layar: 800 x 600 piksel
- Paddle Kiri: Pemain (kontrol `W` untuk naik, `S` untuk turun)
- Paddle Kanan: AI (mengikuti posisi vertikal bola)
- Bola memantul pada dinding atas/bawah dan paddle
- Sistem skor: bola melewati sisi kiri = poin AI, melewati sisi kanan = poin Pemain

## Cara Menjalankan
1. Pastikan Python 3 sudah terpasang.
2. Install dependensi:
   ```bash
   pip install -r requirements.txt
   ```
3. Jalankan game:
   ```bash
   python pong.py
   ```

## Kontrol
- `W`: Gerak ke atas
- `S`: Gerak ke bawah
- `Esc`: Keluar

Selamat bermain!
