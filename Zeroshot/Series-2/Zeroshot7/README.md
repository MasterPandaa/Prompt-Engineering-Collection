# Snake Game (Pygame)

Game Snake klasik menggunakan Python dan Pygame.

## Spesifikasi
- Layar 600x400 piksel
- Kontrol dengan tombol panah (tidak bisa langsung berbalik arah)
- Skor bertambah 1 setiap memakan makanan
- Game over jika menabrak dinding atau tubuh sendiri
- Tekan Enter untuk restart, Esc untuk keluar pada layar Game Over

## Cara Menjalankan
1. Pastikan Python 3.8+ sudah terpasang.
2. (Disarankan) Buat virtual environment.
3. Install dependensi:
   ```bash
   pip install -r requirements.txt
   ```
4. Jalankan game:
   ```bash
   python snake.py
   ```

## Kontrol
- Panah Atas: bergerak ke atas
- Panah Bawah: bergerak ke bawah
- Panah Kiri: bergerak ke kiri
- Panah Kanan: bergerak ke kanan

Selamat bermain!
