# Snake Game (Pygame)

Game Snake klasik dibuat dengan Python dan Pygame.

## Spesifikasi
- Layar: 600 x 400 piksel
- Kontrol: Panah (Atas/Bawah/Kiri/Kanan)
- Aturan: Tidak bisa langsung membalik arah (misal dari kanan langsung ke kiri)
- Makanan: Muncul acak, menambah panjang ular dan skor +1
- Game Over: Jika menabrak dinding atau tubuh sendiri
- Tampilan skor di sudut kiri atas

## Persiapan
1. Pastikan Python 3.8+ sudah terpasang.
2. Instal dependensi:
   ```bash
   pip install -r requirements.txt
   ```

## Menjalankan
```bash
python main.py
```

## Kontrol Tambahan
- ESC: Keluar
- R (saat Game Over): Mulai ulang permainan

Selamat bermain!
