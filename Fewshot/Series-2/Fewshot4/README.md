# Snake Game (Pygame)

Game Snake sederhana menggunakan Pygame.

## Spesifikasi
- Layar: 600x400
- Ukuran blok: 20x20 piksel
- Kontrol: Arrow keys
- Tidak bisa berbalik arah
- Makanan acak, ular tumbuh saat makan
- Deteksi tabrakan dinding dan tubuh
- Skor ditampilkan

## Cara Menjalankan
1. (Opsional) Buat virtual environment.
2. Instal dependensi:
   
   ```bash
   pip install -r requirements.txt
   ```

3. Jalankan game:
   
   ```bash
   python snake_game.py
   ```

## Kontrol
- Panah atas/bawah/kiri/kanan untuk bergerak
- Saat Game Over: tekan `R` untuk restart, `Esc` untuk keluar
